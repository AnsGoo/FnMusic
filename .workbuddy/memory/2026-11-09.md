## CI Android 构建失败修复
- 现象：`Dependency 'androidx.lifecycle:lifecycle-process:2.7.0' requires ... compileSdk 34`，`:device_info_plus is currently compiled against android-33`。
- 根因：device_info_plus 9.1.2 的 android/build.gradle 写死 `compileSdkVersion 33`，而 app 自身是 36（flutter.compileSdkVersion=36），只有插件模块拖后腿。
- 修法：`android/build.gradle.kts` 里对 subprojects 加 afterEvaluate，用**反射**把 android 扩展的 compileSdk 抬到 36（`setCompileSdk(Int)` / `compileSdkVersion(Int)` / `setCompileSdkVersion(String)` 三种都试）。不能引用 AGP 类型——根脚本 classpath 不含 AGP。
- **顺序坑**：该块必须放在 `subprojects { project.evaluationDependsOn(":app") }` **之前**，否则报 "Cannot run Project.afterEvaluate when the project is already evaluated"。
- 已验证：`./gradlew -q -I probe.gradle help` 探针输出所有模块（含 device_info_plus）compileSdk=36；`flutter build apk --release` 成功（55MB），target 仍为 36。
- 本机 Windows 上 Kotlin 增量编译报 "Could not close incremental caches ... .tab"，几次复现 → `android/gradle.properties` 固定 `kotlin.incremental=false`（CI 全新工作区无收益损失）。
- 本机 `flutter build appbundle` 会报 "Failed to find cmdline-tools"——本机 Android SDK 没装 cmdline-tools，与仓库无关，CI 上正常。

## 锁屏/后台播放接入
- 现象：Android / 鸿蒙真机锁屏后几秒停播。根因不是播放器，是进程被系统挂起：Android 缺前台服务 + MediaSession，鸿蒙缺 backgroundModes + 长时任务。
- Android/iOS：新增依赖 `audio_service ^0.18.19`，新增 `lib/audio/media_session.dart`（`_MfAudioHandler` + `MfMediaSession`），main() 里 runApp 前 `await MfMediaSession.start()`；AppModel 构造时 bind，把锁屏的上一首/下一首接回 `next()` / `previous()`。通知栏媒体控件为 上一首/播放暂停/下一首 + 可拖动。
- AndroidManifest 必须同时有：WAKE_LOCK、FOREGROUND_SERVICE、FOREGROUND_SERVICE_MEDIA_PLAYBACK 三个权限 + `com.ryanheise.audioservice.AudioService`(foregroundServiceType=mediaPlayback) + `MediaButtonReceiver`。已用 merged manifest 验证。
- iOS 补了 Info.plist `UIBackgroundModes: audio`。
- 鸿蒙：module.json5 加 ability `backgroundModes: ["audioPlayback"]` 与 `ohos.permission.KEEP_BACKGROUND_RUNNING`；EntryAbility 注册 MethodChannel `com.seasonyuu.musicfly/background_audio`，用 backgroundTaskManager 起停 AUDIO_PLAYBACK 长时任务；Dart 侧 `lib/audio/background_task.dart` 在 playerStateStream 里「真 playing」后才申请（系统会校验 AVSession 状态，提前申请会被拒）。
- `mf.PlaybackState`（本项目）与 `audio_service.PlaybackState` 同名 → media_session.dart 用 `import 'player.dart' as mf;` 隔开。
- 验证：analyze 0 issue、83 个测试全过、`flutter build apk --release` 成功（55MB）。鸿蒙侧本机没有 ohos toolchain，未编译验证。

## 锁屏控制器补齐（Android 13+ 通知权限 / iOS 音频会话 / 通知图标）
- 关键结论：Android 13+ 不给 POST_NOTIFICATIONS 时，**播放中**的通知还在（FGS 通知豁免），但一暂停服务退出前台、通知降级为普通通知就消失 → 锁屏控制器跟着没了。这是「暂停后点不回播放」的根因。
- 补了：manifest 声明 + MainActivity 里 channel `musicfly/notification` 的 `requestPostNotifications`（Dart 侧在 AppModel._startTrack 首次播放时调，不在启动弹窗）；`res/drawable/ic_stat_music.xml` 单色音符 + `androidNotificationIcon`（默认彩色图标会显示成白方块）。
- 补了 audio_session 显式依赖 + `lib/audio/system_audio.dart`：`AudioSessionConfiguration.music()`，main() 里 runApp 前调用。iOS 不配这个的话切后台直接静音、锁屏没有 Now Playing。鸿蒙无 ohos 实现 → 必须 try/catch。
- 验证：analyze 0 issue、83 个测试全过、`flutter build apk --release` 成功（55MB），merged manifest 确认 POST_NOTIFICATIONS + foregroundServiceType=mediaPlayback，R.txt 确认 ic_stat_music 已打包。

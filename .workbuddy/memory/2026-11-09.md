## Windows 安装包（exe）
- 新增 `scripts/musicfly.iss`（Inno Setup 6，UTF-8 **带 BOM**，否则中文乱码）与 `scripts/inno/ChineseSimplified.isl`（取自 jrsoftware/issrc 官方简体中文，417 行）。产物 `dist/MusicFly-<ver>-windows-x64-setup.exe`（约 11M）。
- 安装形态：PrivilegesRequired=lowest + DefaultDirName={autopf}\MusicFly → 装到 %LocalAppData%\Programs，不弹 UAC；带开始菜单组、可选桌面图标、卸载项，lzma2/max 压缩。
- **坑**：Git Bash 里直接传 `/Qp`、`/Dxxx` 给 ISCC 会被 MSYS 当路径改写，报 "You may not specify more than one script filename" → 调用前必须 `MSYS2_ARG_CONV_EXCL='*'`。
- Inno 会给 setup.exe 的 FileVersion/CompanyName 自动加尾缀 "X"，属正常行为，不用管。
- package_windows.sh 现在同时出 setup.exe + zip，支持 `NO_ZIP=1` / `NO_INSTALLER=1`；已用 `/VERYSILENT` 装到临时目录再静默卸载验证通过（目录清空无残留）。

## 定位：鸿蒙锁屏播控卡片无封面（未改代码）
- 链路：app_model._startTrack → `client.coverUrl(coverId, size:640)` → player._pushSystemMetadata 的 `artUri` → 主通道 `com.ryanheise.just_audio.methods` / `setMetadata` → MainMethodCallHandler → AudioPlayer → MediaAvPlayer.setSessionMetadata.dartArtUri → `setAVMetadata()` 的 `mediaImage`（`MediaAvPlayer.ets:567`）。**传的是 URL 字符串，插件没有下载/转 PixelMap 的代码**。
- 根因判断：`mediaImage` 的图片由 system sceneboard/AVSessionService 自己下载，不带 App 请求头。App 内封面能显示是因为 `lib/ui/widgets.dart:67` 给 CachedNetworkImage 传了 `httpHeaders: fnRelayHeadersFor(url)`；网关链路需要 `Authorization: trim <token>`（fn_connect.dart）、中继链路需要 `Cookie: entry-token`，系统都没有。`musicfree_client._mediaUrl` 只在 subsonicToken 非空时才把 `u/t/s` 拼进 URL，网关免密登录很可能没有它。
- 不是代码回归：`git diff 0e76a3e..HEAD` 显示 MediaAvPlayer 的 mediaImage 赋值和 Dart 的 artUri 参数自「模拟器验证封面正常」那版起一行未改。变的是链路：0bd7fa1 引入 fnOS 统一网关 `/app/musicfree/`、da4c95c 引入免密登录，手机在外网 LAN 探测失败就会落到需鉴权的网关地址。
- 次要放大因素：官方建议 mediaImage 用 PixelMap（网络 URL 还会因 `Content-Disposition: attachment`、特殊字符、>2MB 失败）；coverUrl 为 null 时 Dart 推 `''`，`dartArtUri ?? ...` 被空串短路 → `mediaImage: ''`；setAVMetadata 是 `.then().catch()`，失败不重试。
- 验证法：hilog 抓 `setMetadata from Dart: ... artUri=` / `SetAVMetadata BusinessError`；把 artUri 复制到手机浏览器（无头）打开，401 即实锤；或把服务器地址切回 `http://<NAS-IP>:14533` 直连，封面回来即实锤。
- 修复方向：App 侧用带鉴权头的 http 把封面下载成字节 → 转 PixelMap/本地文件交给 ArkTS，系统只渲染不再自行取网络图；顺带修空串兜底与失败重试。本机无 ohos toolchain，ArkTS 改动无法编译验证。

## FNID 登录的 LAN/WAN 自动切换（用户：内网登录后离开内网就断连）

## 曲库列表加封面（参考 web 端）

- `TrackRow` 新增 44×44 圆角 6 的封面缩略图（`_TrackThumb`），行高 52 → 60；hover 时封面压暗显示播放三角，当前播放曲加 1.2px accent 描边。专辑详情页 `showCover: false`（表头已有大封面），歌单详情页保留。
- 封面 id 策略：优先歌曲级 `coverArt`（`so-<songId>`），失败自动回退专辑 id（实测两种 id 都能被 `rest/getCoverArt` 接受；`so-` 只有部分歌有内嵌图，缺图时后端返回 HTTP 200 + XML `Cover art not found`）。`CoverImage` 因此新增 `onFailed`（走 `CachedNetworkImage.errorListener`），`_TrackThumb` 据此切换。
- 缩略图统一请求 `size=96`（`AppModel.coverUrl(coverId, size:)` 新增参数），服务端返回真实 96×96，避免列表拉 320 大图。
- 新增 `lib/data/http_defaults.dart`：`main()` 设 `HttpOverrides.global = LocalNetworkDirect()`，让图片加载器（cached_network_image 自带 HttpClient，不走 API client）对 localhost / RFC1918 也 DIRECT，绕过系统 `HTTP_PROXY` 劫持。`MusicFreeClient` 复用同一个 `proxyFor`，删掉私有副本。
- 新增 `test/track_row_test.dart`（覆盖尺寸 60/52、封面存在性、播放图标），共 12 个测试全过。

- 服务端由用户自行启动，地址 `http://localhost:14533`，账号 admin/admin；Subsonic 认证必须走 token（`t=md5(password+salt)&s=salt`），仅 `p=password` 会被拒（`code 50 Unsupported authentication method`）。
## 播放报错排查（歌单「不该用情」）

- 根因不在客户端：歌单 12 首都是 FLAC，全部来自 WebDAV 源 `http://192.168.124.18:5005/`（用户 NAS），当前 **ping 100% 丢包、HTTP 000**。服务端对这类请求返回 **HTTP 200 + XML** `{"error code=70 "Media file not found"}`，AVPlayer 只会报 `-11850 Operation Stopped`，所以客户端看起来像"播放错误"。
- 本地源（`music-free/backend/music`，55 个文件）的歌流正常：`rest/stream?id=7a101edb...` 返回 `audio/mpeg`、7.7MB、ID3 头；真机日志也出现 `setUrl ok` + `started=true track=半点心`。测试本地/远端可用 `curl --noproxy '*'` + Subsonic token。
- 新增 `lib/audio/stream_probe.dart`：`probeStream(url)` 取前 1KB 判断 content-type，非 audio 则解析 XML `message=`；`explainServerMessage()` 转成中文（not found → "文件在服务端找不到了（媒体源可能离线）"）。
- `FnPlayer`：`play()` 现返回 bool；失败时先 probe 得准确原因；`errorStream` 也走同一 probe（按 trackId 去重，避免重复请求）；过滤 `PlayerInterruptedException` / "aborted" 消息，避免切歌 abort 被误判为坏源（`AudioPlayer.m` 里 `abortExistingConnection` 会发 error）。
- `PlaybackState.copyWith` 修 bug：`error` 之前每次 copyWith（position tick）都被清空，错误提示只闪一帧；新增 `clearError` 语义。
- `AppModel`：`onFailed` → `_handleFailure` 自动跳下一首，连续 6 首失败（`_maxFailedSkips`）停止并提示"请检查媒体源"；只弹第一条 snackbar；`playFrom/next/previous` 重置计数。
- 新增测试 `test/stream_probe_test.dart`（HttpServer 模拟 200+XML，3 例）、`test/playback_queue_test.dart`（FakePlayer 驱动跳过逻辑，3 例），共 21 个测试通过。
- 调试手法：`flutter run -d macos` 在本机沙箱里 debug 连接会失败（"log reader stopped"）；改用 `--dart-define` + release 构建把日志写进 `Directory.systemTemp`（沙盒内 `~/Library/Containers/com.seasonyuu.fnmusic/Data/tmp/`）读回。临时日志与自动播放开关已全部移除。

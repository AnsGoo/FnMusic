## 修复：竖屏播放详情页「BOTTOM OVERFLOWED BY 31 PIXELS」

- 现象：真机竖屏 360×780 在歌名下方出现黄黑斜纹溢出条。临时诊断测试复现：360×780 溢出 30px、360×824 溢出 23px、390×844 溢出 20px、320×640 溢出 52px、411×914 溢出 9.4px；280×500 另有 21px 来自歌词空状态。
- 根因：上一轮把竖屏唱片放大成 `maxHeight * 0.72`，但同一 Column 下还有固定高度的歌名/歌手/专辑三行，`0.72H + credits > H`；`Flexible` 只给上界约束，内部 Column 就溢出。歌曲带 album 时多一行，溢出更明显（这正是截图 31px 的来源）。
- 修法（`lib/ui/now_playing.dart`）：窄屏 coverColumn 外层 `Flexible` → `Expanded`（紧约束）；内部改成 `Expanded(LayoutBuilder(唱片)) + 固定高度 _credits(...)`，唱片尺寸 = `min(宽度×0.78, 剩余高度-4, 300)`，**不再按高度比例硬算**。抽出 `_disc` / `_credits` 供桌面分支复用（桌面仍是 0.62/0.56 居中布局）。封面:歌词 flex 由 5:4 调成 6:4 把唱片补回参考图观感；按歌词区实际可用高度 `>= 140` 决定极矮屏是否隐藏歌词面板，避免 EmptyState 溢出。
- 回归：`test/now_playing_test.dart` 新增 8 个尺寸（含 280×500 / 900×500 / 1440×900）的 `tester.takeException() == null` 断言。`flutter analyze` 无问题；`flutter test` **157 项全通过**。临时诊断测试与 golden 截图已删除，未打包安装包。

## PC 端播放队列/历史改到右侧停靠面板

- 用户确认的设计：PC（宽 >= 900）用**右侧停靠面板**（非模态、主内容让位、无遮罩）；从全屏播放详情页点「播放列表」先关全屏页再展开面板；移动端继续用底部弹窗。
- `lib/ui/queue_sheet.dart`：`QueueSheet` 新增 `docked` 形态（标题栏「播放队列」+ 关闭按钮，去掉拖拽把手/圆角/SafeArea/Align），与移动端共用同一 body（tabs、来源、列表、底部两个 pill）。新增 `kDockedQueueBreakpoint = 900` 和统一入口 `showQueue(context, {fromFullPlayer})`：窄屏走 `showQueueSheet`，宽屏 `toggleQueuePanel`，全屏页走 `closeNowPlaying + openQueuePanel`。
- `AppModel`：新增 `queuePanelVisible` + `openQueuePanel / closeQueuePanel / toggleQueuePanel`，logout 时重置。
- `HomeShell._desktop`：面板是**内容区 Row 的右侧兄弟**（歌库 `Expanded` 自动让位），不是整行末尾——放整行末尾会把桌面播放条压到 ~390px 并横向溢出；面板止于播放条上方，播放条仍横跨整个内容区。宽度 `(maxWidth*0.28).clamp(300,360)`。
- 三处入口（player_bar wide/compact、now_playing）统一走 `showQueue`；桌面播放条队列按钮变成高亮 toggle（打开时 tooltip「关闭播放列表」），面板 header 关闭按钮 tooltip 为「关闭播放队列」。
- 顺手修两处窄宽溢出：`PlayerBar._wideLayout` 新增 `availableWidth` 参数，<760 时把固定 302px 的右侧镜像 `rightSpan` 降为 0；`home_view.dart` 的 `_SectionCard` header 用 `Flexible`/`Expanded` + ellipsis 让标题与副标题可收缩，副标题颜色 `Mf.faint` → `Mf.muted`。
- 回归：`test/queue_sheet_test.dart` 新增 8 项（状态开关、PC 停靠无遮罩且贴右边界、两种关闭方式、全屏页回主界面、手机仍底部弹窗、900/1024/1440 无溢出）。`flutter analyze` 无问题；`flutter test` **165 项全通过**。用临时 golden 渲染核对了 1200×800 PC 布局后删除；未打包安装包。
